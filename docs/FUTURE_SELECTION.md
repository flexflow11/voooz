# Будущий подбор с нейросетью

Первоначально эти пожелания были отложены до подключения нейросети; актуальное состояние описано выше.

- В финальной подборке показывать **3 вуза**; карточки должны открывать подробную информацию.
- В каждой карточке отобразить оценку шансов в процентах: аккуратная круговая шкала с выделенным сектором и числом в центре, сдержанная стилистика приложения. Референс пользователя — круг CaseBattle.
- Для выбора учитывать **число бюджетных мест** в конкретной программе/конкурсной группе, год приёма, кампус и набор вступительных испытаний. Не использовать общее количество мест по всему вузу как число мест на выбранной программе.
- Для предусмотренного пользователем сценария из трёх ЕГЭ соблюдать **потолок конкурсного балла 310**: до 300 за три экзамена и до 10 за индивидуальные достижения. Не суммировать все 4–5 указанных ЕГЭ как один конкурсный балл; выбирать набор, требуемый программой. Отдельно проверить программы с дополнительными испытаниями и особыми условиями, прежде чем распространять это ограничение на них.
- **Правила достижений разные у каждого вуза.** Хранить подтверждённые правила на конкретный год, вычислять баллы отдельно для каждой программы/вуза и применять их ограничения. Олимпиадные льготы не заменять произвольной надбавкой.
- Добавить прямую кнопку **«Подать документы»** с проверенной ссылкой на официальный раздел подачи/личный кабинет абитуриента. Не подменять её главной страницей вуза, если адрес подачи не подтверждён.

Проценты требуют обоснованной методики и достаточных исторических данных. Число, придуманное моделью по описанию вуза, нельзя представлять как измеренную вероятность поступления. При реализации определить источники, год, допущения и способ проверки качества оценки; честно показывать отсутствие данных.

Связь с исходными требованиями: сохраняются поступившие ЕГЭ, специальность и достижения; нейросеть помогает искать/разбирать подтверждённые источники. Подбор не даёт гарантии зачисления. Сейчас действует предварительный тематический поиск без процентов, без вымышленных проходных баллов и без единой формулы бонусов.
