# Официальные источники для локальной модели

У локальной Qwen нет встроенного доступа к интернету. `server/evidence.mjs` отдельно получает небольшой набор документов и передаёт модели их текст; ответы модели не становятся результатами веб-поиска.

## Что получает сборщик

`createEvidenceCollector(options).collect(universities)` принимает только список вузов из серверного каталога. В HTTP-запросе пользователя нет произвольного URL для скачивания. Результат:

```js
{
  documents: [{ url, title, text, universityId, retrievedAt }],
  sources: new Set(), // точные URL действительно прочитанных HTML-страниц
  failures: [{ universityId, code }],
  notice: '...'
}
```

Сначала запрашивается официальный сайт из каталога, затем реальные ссылки на приём, правила, места, результаты и достижения, найденные на прочитанных страницах. Пути `/admission` и подобные не конструируются по предположению. Ссылки на сторонние сайты, PDF, архивы, изображения и офисные документы не скачиваются. Сборщик не выполняет JavaScript и не имеет OCR: значительная часть вузовских PDF и динамических кабинетов останется недоступной.

По умолчанию обрабатываются три вуза, не более четырёх страниц каждого, глубина обхода до двух переходов. До девяти документов и суммарно 12 тысяч символов распределяются между вузами по очереди; страницы приёма получают приоритет перед главной. Размер отдельного HTTP-ответа ограничен 1 MiB, запрос — 7 секундами, весь сбор — 20 секундами. Успешно прочитанные фрагменты кешируются в памяти до 24 часов, не более 128 вузов/официальных сайтов. Неуспешные ответы не создают самостоятельные записи кеша. Персональная анкета при получении источников не передаётся вузам.

Это ограниченный обход связанных HTML-страниц, **не полный поиск по всем вузам и не автоматически обновляемый реестр приёмных кампаний**. При сетевой ошибке, CAPTCHA, неподдерживаемом формате, пустом HTML или отсутствии нужной страницы сборщик возвращает отсутствие сведений. Бюджетные места и проходные баллы не заменяются выдуманными значениями.

## Сеть и безопасность

Допускаются только HTTPS и исходный официальный домен из каталога либо его поддомены. Ссылки с учётными данными, нестандартным портом или числовым IP отвергаются. Каждый запрос и каждый переход редиректа заново проверяют DNS: loopback, локальные, частные, link-local, multicast и зарезервированные диапазоны IPv4/IPv6 запрещены; смешанный публичный/частный ответ также не принимается. При прямом HTTPS-соединении используется проверенный IP с сохранением исходного Host/SNI и стандартной проверкой TLS-сертификата, что не позволяет повторному DNS-разрешению поменять адрес назначения.

Если сервер настроен на `HTTPS_PROXY`/`HTTP_PROXY`, сборщик сохраняет этот маршрут и выполняет CONNECT к имени официального сайта с последующей проверкой TLS. `NO_PROXY` применяется только согласно явным настройкам процесса. Проверка DNS перед запросом сохраняется, но при проксировании конечный IP разрешает сам прокси: его политика должна дополнительно блокировать частные/локальные адреса и учитывать DNS rebinding. Сборщик не обходит сетевой прокси, не отключает TLS и не меняет VPN. Учетные данные прокси не возвращаются в диагностике.

В текущей облачной среде живой сбор страницы НИУ ВШЭ завершился отсутствием документов из-за недоступного DNS/сетевого маршрута. Источники и числа при этом не были выданы. Успешное получение реальных вузовских страниц нужно проверить на размещённом сервере с разрешённой сетью; тесты с подставными HTML-ответами проверяют контракт и ограничения, а не доказывают доступность внешних сайтов.

Наличие URL в `sources` подтверждает происхождение фрагмента, а не истинность каждой интерпретации модели. Серверная проверка года, программы, кампуса, предметов, мест и правил достижений остаётся обязательной. При дальнейшем сокращении контекста модели разрешены только URL тех документов, которые действительно попали в её запрос.
