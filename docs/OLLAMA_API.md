# Локальная Qwen через Ollama

`server/ollama.mjs` подключает локально запущенную модель без API-ключа и без платного провайдера. По умолчанию используется `qwen2.5:0.5b` через `http://127.0.0.1:11434`. Это небольшая модель для начального запуска; качество извлечения сложных условий приёма нужно проверять на реальных документах. Свой сервер, электричество и ресурсы хостинга могут стоить денег; платы за токены этому адаптеру нет.

Посетитель сайта обращается только к Node API приложения. Ему не нужны Ollama, собственная модель, ключ или VPN. Сам Ollama работает на сервере, а не внутри скачанного HTML. Его порт не следует публиковать в интернет.

## Контракт

`createOllamaResearch({baseUrl, model, fetchImpl, cacheDir, timeoutMs})` возвращает `{configured, provider:'Qwen · Ollama', model, missing, checkHealth, research}`. `configured` означает допустимость настроек; для готовности процесса и установленной модели нужно вызвать `checkHealth()`.

- `checkHealth()` делает `GET /api/tags` с таймаутом 3 секунды и возвращает `{available, modelInstalled, model, reason?}`. Ответ с моделью, обозначенной как удалённая через `remote_host`/`remote_model`, не считается установленной локальной моделью.
- `research(kind, query)` делает `POST /api/chat`: `stream:false`, `temperature:0`, `num_ctx:8192`, `num_predict:1200`, `num_thread:4`, `keep_alive:'5m'`. Для `admissions_recommendations` с известным списком вузов `format` содержит JSON Schema: до трёх результатов, `universityId` только из переданного перечня, обязательные `reason` и `admission` (объект или `null`), без посторонних полей. Все вложенные объекты имеют явный набор полей, массивы и строки ограничены; рекурсивный свободный JSON не допускается. Источники выбираются только из URL фактически переданных документов. Если документов нет, `admission` разрешён только как `null`. Пустой массив разрешён: схема не вынуждает придумывать доказательства. Для других задач используется `format:'json'`. Таймаут по умолчанию — 180 секунд: первый запрос на CPU может включать загрузку весов.
- Используются только локальные адреса `localhost`, `127.0.0.1`, `[::1]`, Docker-сервис `ollama` или `host.docker.internal`; протокол HTTP/HTTPS, необязательный порт. Произвольные внешние адреса, авторизация в URL, пути и query-параметры не принимаются. Имена моделей с отдельным маркером `cloud` запрещены. При запуске процесса Ollama следует также отключить облачные функции через `OLLAMA_NO_CLOUD=1`.
- Модель не имеет встроенного веб-поиска. Документы передаёт сервер в `query.evidence:[{url,title,text}]`. В модель попадают максимум 9 непустых HTTPS-документов, общий объём текста — до 6 000 символов с равным бюджетом между документами. Весь сериализованный запрос ограничен 16 000 символами.
- `sources:Set` формируется только из точных URL действительно переданных документов. Ссылки и `sources`, написанные моделью, не дают подтверждения. Документы, исключённые лимитом, также не становятся источниками. Наличие источника подтверждает происхождение текста, а не правильность каждого вывода нейросети.
- Без документов можно получить тематическое объяснение по анкете, но подтверждённые баллы, места, правила достижений и страницы подачи недоступны. Системная инструкция требует `admission:null`/`passingScore:null`, а серверные проверки независимо отвергают цифры без источников.
- Ответ должен быть завершённым JSON-объектом. Ошибки модели, незавершённые/обрезанные ответы и ответы с метаданными удалённого облачного выполнения не принимаются. Размер ответа ограничен 2 MiB. Тексты ошибок процесса не выдаются пользователю.
- Идентичные параллельные запросы объединяются. Одновременно допускаются два разных локальных вычисления. Кеш действует 24 часа, до 64 записей в памяти и на диске. Кеш не хранит исходные документы, но может содержать персонализированные объяснения и должен оставаться закрытым; его можно отключить, не задавая `cacheDir`.

Арифметика по-прежнему выполняется в `shared/admissions.mjs`: выбранная тройка ЕГЭ, вузовские условия достижений, не более 10 бонусных баллов и 310 всего. Произвольный процент из ответа модели не принимается. При недостатке официальных данных результат остаётся неизвестным.
