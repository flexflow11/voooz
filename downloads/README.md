# Готовая версия для просмотра

`voooz-open-v2.zip` — обновлённое автономное приложение: подсказки анкеты в стиле интерфейса, три понятных шага на главной и локальные фотографии ведущих вузов. `voooz-open.zip` содержит ту же последнюю сборку. Скачайте архив через GitHub, полностью распакуйте его, затем откройте `voooz/index.html` в браузере. Установка Node и запуск сервера для просмотра не нужны.

Полный исходный код находится в корне этой ветки репозитория. Это снимок для просмотра; исходные данные и ограничения описаны в основном README.
