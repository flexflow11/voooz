# Готовая версия для просмотра

`voooz-open.zip` — собранное автономное приложение. Скачайте архив через GitHub, полностью распакуйте его, затем откройте `voooz/index.html` в браузере. Установка Node и запуск сервера для просмотра не нужны.

Полный исходный код находится в корне этой ветки репозитория. Это снимок для просмотра; исходные данные и ограничения описаны в основном README.
